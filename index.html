한 줄 요약

씀씀이는 이름·연락처 같은 개인정보를 받지 않습니다. 계정이 없고, 기록은 이 앱을 깐 기기 밖으로 나가지 않습니다. 앱을 고치는 데 참고하려고 사용 통계를 보내며, 설정에서 끌 수 있습니다(아래 「사용 통계」).

수집하는 정보

  • 회원가입이 없습니다. 이메일·이름·전화번호를 묻지 않습니다.
  • 광고가 없습니다. 광고 식별자를 읽지 않습니다.
  • 위치·연락처·사진·캘린더에 접근하지 않습니다.
  • 사용 통계를 보냅니다. 무엇이 나가는지는 아래 「사용 통계」에 전부 적었습니다.

기기에 저장되는 것

앱에 남긴 것은 기기 안의 파일 하나에 저장됩니다.

  • 기록 — 소비 이름, 메모, 카테고리, 크기, 할인·적립 여부, 나랑 맞았는지, 소비가 없었던 날의 상황과 기분 같은 것
  • 설정 — 알림 시각, 사용 통계를 보낼지, 설치 번호(아래 「사용 통계」) 같은 것

정확한 금액을 받지 않습니다. 이 앱은 얼마를 썼는지 묻지 않고, 그래서 갖고 있지도 않습니다.

이 파일은 앱 전용 저장 공간에 있어 다른 앱이 읽을 수 없습니다. 앱을 지우면 함께 지워집니다.

백업

휴대폰이 기기를 백업할 때 이 파일이 함께 포함될 수 있습니다 — 안드로이드는 Google Drive, 아이폰은 iCloud입니다. 이는 휴대폰 제조사·운영체제와 사용자 사이의 일이며 씀씀이는 관여하지 않고, 백업 내용을 열어볼 수도 없습니다. 백업을 켜고 끄는 것은 휴대폰 설정에서 합니다.

알림

알림은 전부 기기 안에서 만들어집니다(로컬 알림). 원격 푸시를 쓰지 않으므로 푸시 토큰이 없고, 사용자가 무엇을 언제 기록했는지 서버가 알 방법이 없습니다.

알림 권한은 거부해도 됩니다. 거부해도 앱의 모든 기능이 동작합니다.

앱 업데이트

앱을 열 때 새 버전이 있는지 확인합니다. 이때 나가는 것은 다음 셋뿐입니다.

무엇예
플랫폼android
앱 버전1.0.0
현재 설치된 업데이트 식별자무작위 문자열

기록은 보내지 않습니다. 소비 이름도, 크기도, 답도, 무지출 기록도 나가지 않습니다. 계정이 없으므로 이 요청이 누구의 것인지 알 수 없고, 저장되지도 않습니다 — 무엇을 내려줄지 고르는 데만 쓰입니다.

이 확인은 앱을 고쳤을 때 스토어 심사를 기다리지 않고 고친 것을 보내기 위한 것입니다.

사용 통계

사람들이 씀씀이를 계속 쓰는지, 다시 묻는 질문에 답을 하는지 알기 위해 분석 서비스 PostHog로 사용 통계를 보냅니다.

보내는 것

앱이 미리 정해 둔 값과 숫자만 보냅니다. 사용자가 직접 쓴 글자는 어떤 경우에도 보내지 않습니다.

종류예
앱을 어떻게 쓰는지앱을 열었는지, 어느 화면을 봤는지, 기록을 남겼는지, 질문에 답했는지와 그 횟수
기록의 겉모양소비의 크기 단계, 메모·카테고리를 채웠는지, 쌓인 기록 수, 설치하고 며칠째인지
설치 번호와 기본 정보앱이 만든 무작위 설치 번호, 앱 버전, 휴대폰 OS 버전

설치 번호는 기기 ID가 아닙니다. 앱을 지우면 함께 지워지고, 다시 깔면 새 번호가 됩니다.

보내지 않는 것

  • 직접 쓴 글자. 소비 이름, 메모, 직접 만든 카테고리 이름.
  • 답과 기분. 소비가 나랑 맞았는지, 소비가 없었던 날의 상황과 기분.
  • 발견의 내용. 발견이 생겼다는 사실만 셉니다.
  • 기기나 사람을 알아보는 값. 기기 ID, 광고 ID, 전화번호, 이메일.
  • 위치. 위치 권한을 쓰지 않고, 인터넷 주소(IP)로 지역을 추정하는 기능도 꺼 두었습니다. IP 주소는 저장하지 않도록 설정해 두었습니다.

통계는 광고에 쓰지 않습니다.

언제부터 보내나

이 기능이 들어간 업데이트 뒤 처음 앱을 열면 먼저 알리는 화면이 뜹니다. 그 화면을 넘기기 전에는 아무것도 보내지 않습니다.

끄는 법

설정 → 사용 통계 보내기를 끄면 그때부터 아무것도 보내지 않습니다. 처음 알리는 화면에서 보내지 않을래요를 눌러도 같습니다. 꺼도 앱의 모든 기능이 똑같이 동작합니다.
